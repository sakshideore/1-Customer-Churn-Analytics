# Customer Churn & Retention Analytics

## Project Overview
This project analyzes customer churn for a telecommunications business using Python, SQL Server, and Power BI.

The objective is to identify customer segments with high churn rates, understand customer behavior, and recommend retention strategies.

## Business Problem
The telecom business wants to understand:
- How many customers are leaving?
- Which contract types have the highest churn?
- Which payment methods are associated with higher churn?
- How does customer tenure relate to churn?

## Tools & Technologies
- Python: Pandas, NumPy, Matplotlib, Seaborn
- SQL Server: Data cleaning, aggregation, business analysis
- Power BI: Interactive dashboards and DAX measures
- GitHub: Project documentation and version control

## Dataset
IBM Telco Customer Churn dataset.

The dataset contains 7,043 customer records and 21 columns.

Dataset source: https://www.kaggle.com/datasets/blastchar/telco-customer-churn

## Project Workflow
1. Data understanding and exploration
2. Data cleaning and preprocessing
3. Exploratory Data Analysis using Python
4. SQL-based business analysis
5. Power BI dashboard development
6. Business insights and recommendations

## Key Findings
- Total customers: 7,043
- Churned customers: 1,869
- Retained customers: 5,174
- Overall churn rate: 26.54%
- Month-to-month contract churn rate: 42.71%
- Electronic check churn rate: 45.29%

## Business Recommendations
1. Develop retention offers for month-to-month customers.
2. Investigate the high churn rate among electronic check customers.
3. Improve customer onboarding during the first year.
4. Monitor customer churn by contract and payment method.
